# Credit Card Animation UI

Uma interface interativa de cartão de crédito com animação, destaque visual e atualização em tempo real dos campos de número, titular, validade e CVV.

## ✨ Funcionalidades

- Efeito de flip do cartão ao focar o campo CVV
- Destaque animado do campo ativo
- Detecção automática da marca do cartão
- Atualização dinâmica do nome do cartão e do logo
- Layout responsivo

## 🧩 Tecnologias

- HTML
- CSS
- JavaScript

## ▶️ Como executar

1. Abra o arquivo `index.html` em um navegador.
2. Ou inicie um servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## 📁 Estrutura do projeto

- `index.html` — estrutura da interface
- `style.css` — estilos e animações
- `script.js` — lógica de interação e detecção de bandeira

## 📝 Descrição curta para GitHub

Projeto de UI interativa de cartão de crédito com efeitos visuais, detecção de bandeira e atualização em tempo real dos dados informados pelo usuário.
